##  Learning Approach

My study routine follows this pattern:

1. Learn a concept.
2. Read the official documentation.
3. Solve multiple coding exercises.
4. Refactor my solutions where necessary.
5. Commit my progress to GitHub with meaningful commit messages.
6. Reflect on what I learned before moving to the next topic.

This approach helps me focus on understanding concepts rather than memorizing syntax.
